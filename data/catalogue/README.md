# Shanghai source batch

`shanghai.json` is the explicitly curated, stable-order initial publication. Load it with `npm run catalogue:load` after applying migrations. The command validates the complete batch before one atomic replacement; invalid input preserves the previous publication. An optional file argument supports a separately reviewed batch: `npm run catalogue:load -- /absolute/path/batch.json`. There is no public ingestion endpoint.

Six independently sourced branches span food/cafés and source-described areas including Zhangyuan, West Bund, the Bund and former French Concession. Names, exact branch/unit addresses, categories and area labels come from the cited venue, project-architect, municipal tourism and creator pages observed on 12 October 2026. Acquisition times were not separately returned, so capture dates record the observation day. Source publication dates are null except creator metadata. Area labels do not establish administrative polygons. Current operation is unknown; confirm before travelling.

This batch retains short original summaries, factual branch details and citations. It reproduces no full source article, photograph or provider-card payload. Venue descriptions and promotional recommendations are attributed; they are not customer reviews. No editorial trending/local-favourite/highly-reviewed classification is assigned. Prices, hours, ratings, counts, coordinates and provider IDs remain unknown.

Each Apple URL was actually fetched and loaded a public address-search shell preserving the stated query. `qualification=qualified` applies only to that external address-search handoff, as `linkKind=search`, surface and qualification notes specify. Search results, exact provider match, pins, navigation, native behaviour, reviews and live APIs are unverified. No Apple/Amap data licence, in-app maps, coordinate reuse, overseas eligibility or provider-derived retention rights follow from this result. Research-only uncertain cards and historical branch candidates are excluded.

A publication may also explicitly have `status=unavailable`, empty `places` and a concrete `unavailableReason`; unknown or unqualified candidates must not be padded into a valid batch. Real published batches require at least six branch identities, both food/café categories, two source-described areas and purpose-qualified outbound references. The loader rejects extra fields, duplicate identities, wrong cities, missing evidence associations and unsupported editorial claims. It trusts reviewed curator evidence; validation does not independently verify a venue or confer data rights.
